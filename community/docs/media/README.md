# Screenshots

Images used by the READMEs. Keep file names stable: the READMEs link to them.

| File | What it shows | Used in |
| --- | --- | --- |
| `overview.png` | Main dashboard: agent cards, the race and the charts, with two or three agents active. | README hero |
| `mini-mode.png` | Mini mode: a column of agent cards. | Features › Mini mode |
| `race.png` | The 3D race with a runner raising a hand. | Features › The race |
| `analytics.png` | Tokens and estimated cost by agent and model over 24 h. | Features › Analytics |
| `workspace.png` | A workspace with several repositories and the repository filter. | Features › Workspaces |
| `sessions.png` | A session summary and its timeline. | Features › Sessions |

Guidelines:

- Use a demo workspace: no real client names, private paths, prompts or tokens on screen.
- PNG at 2× (about 1800 px wide), optimised (`oxipng`, `pngquant`).
- GIFs, if you add any, stay under 5 MB.
